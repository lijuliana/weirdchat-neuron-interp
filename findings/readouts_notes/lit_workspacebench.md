# Literature notes: WorkspaceBench, the Jacobian-lens family, and verbalized readouts

Compiled 2026-11-04 from web sources only (no repo edits). Every number below was read from the cited page; where a page's numbers live only in figures I say so rather than guess. Our setting, for the "differs from ours" lines: no hidden information; the weird behavior emerges in ordinary chat and is visible in the transcript once it happens; every method reads the same residual state at the same position the text judge reads; descriptions are scored by a blind judge; lenses gave AUROC .51-.54 vs .56 for a transcript-only judge; a J-lens keyword direction used as an intervention removed 33% of a behavior.

## 1. WorkspaceBench and its artifacts

### 1.1 WorkspaceBench: Evaluating Interpretability Methods for the Global Workspace
- Authors: Camila Blank, Agam Bhatia, Euan Ong, Neel Nanda (MATS). Posted LessWrong / Alignment Forum 23 Sep 2026.
- URL: https://www.lesswrong.com/posts/Zeg2JztbdhguL48uH/workspacebench-evaluating-interpretability-methods-for-the
- Code: https://github.com/camilablank/workspace-bench ; item banks: https://huggingface.co/datasets/camilablank/workspace-bench ; Oracle-lens checkpoint: https://huggingface.co/agu18dec/olens_and_ar
- Summary. A benchmark of 3,356 items in 27 "eval families" (the post's own list shows ~22) that asks whether an activation-to-text tool can surface the "global workspace" of Qwen3.6-27B, defined as intermediate variables the model computes during the forward pass but does not write. Families: basic readout, multihop, multilingual, poetry (planned rhyme), typo correction, directed modulation, chained/arithmetic/brew intermediates, buggy code, agentic misalignment, jailbreak recognition, association (basic/conjunctive/user-modeling/role-bound), relational multihop, hallucination, J-lens precision/recall, moral rationale. Readouts compared: logit lens, J-lens, R-lens, tuned lens (single-token, top-10 tokens at layers 20-60 step 4), and multi-token methods NLA (one ~250-token sample at layer 42), SAE feature descriptions, Patchscopes, Template lens (top-10 phrases), Oracle lens (4 bullets, ~90 tokens), with SFT-only and RL variants of NLA/Oracle lens. Pass rule: an item passes if ANY (layer, position) cell passes. Judges: Gemini-3.8-Flash for most families, Sonnet-5 for safety; regex only for the families inherited from the J-lens paper. Single-token outputs are passed through a summarizer LLM that does not see the prompt.
- Item construction: the intermediate must be logically inferable from the prompt; the model must answer correctly >80% of 10 rollouts at T=0.8 without CoT; the intermediate must not appear in the prompt and the model must not state it; one valid solution path.
- Baselines: "prompt-only" (a model reads the prefix and answers "what would a model be thinking of here?") and "lucky guess" (an LLM picks multiple-choice options without the question). Crucially the authors write: "Many of the tasks in WorkspaceBench were selected precisely because we logically inferred from the prompt text alone" and therefore do NOT treat strong prompt-only performance as evidence against a reader. The prompt-only baseline is reported as a floor beside the score, not subtracted from it (except in a few families, see 1.2).
- Numbers: all headline scores, hallucination rates and J-lens precision/recall are in figures with no alt text; the post text gives none. Qualitative findings: single-token readers are "reliable" but "single tokens have inherent limitations that leave a lot of important workspace representations unreachable"; "NLAs are extremely prone to confabulation" ("nearly every NLA readout contains some type of claim" contradicted by context); J-lens becomes "more competitive than before" once summarized; methods that do well overall "also tend to perform better on safety-related tasks". No clear winner is named in text. Comparison "not a strict scientific comparison" in readout budget.
- Causal tests: none. In the comments Burny asked about interventions; Neel Nanda replied they are "much less method agnostic" and out of scope.
- Limitations stated: judge quality matters ("weaker judges let a lot of false positives seep through"); some association / directed-modulation targets cannot be confirmed as held; built for Qwen3.6-27B only; lower precision vs J-lens "doesn't necessarily imply hallucination".
- Differs from ours: every item is engineered so the target is ABSENT from the text (filtered to not appear in prompt or output), and the score is a pass if any layer/position hits; there is no condition where a text judge and a lens judge read the same position with the same information. The prompt-only floor is reported but explicitly not used to discount readers, so the benchmark cannot show lens uplift over text, which is exactly the quantity we measured.
- Flag: examples (carnaval, Fe/iron, exfil-weights) are illustrative; no random-position control; prompt-only baseline present but not subtracted.

### 1.2 workspace-bench GitHub README / dataset card (same authors)
- URLs: https://github.com/camilablank/workspace-bench ; https://huggingface.co/datasets/camilablank/workspace-bench
- Summary. The repo README (updated through "plan 0040", late Oct 2026) replaces the lesswrong-era judge with Claude Opus 5.5 for all judged families (Sonnet-5 pinned for agentic_misalignment and jailbreak_recognition), adds "HallucinationBench" (weighted share of hallucinated claims), and documents per-family floors. Several families now report net = strict - foil (sandbagging, user_modeling) or value - cross permutation nulls (arithmetic intermediates, directed modulation). Floors that appear in text: association chance 1/8; moral rationale options-only guesser floor 0.831 (v4 bank 0.509; v5 "always no-side" 0.917); relational multihop options-only 0.062/0.064 vs chance 1/18; "knowledge cutoff": stock Qwen given only the text scores 0.486, TYING the lens, so the family "can't separate reading the activation from decoder priors"; hinted cutoff: prompt-only YES/NO predictor +0.49 vs frozen O-lens +0.09 / +0.11; math shortcuts O-lens +0.04 (CI [-0.07, 0.16]) vs prompt-only +0.03; multi-token typo: frontier text readers solve 83/85 from the prompt alone (family near ceiling); poetry: Opus prompt-only 0/139. On buggy_code "a silent lens scores about 2.96". Token-list methods score ~0 on relational multihop "by design" (no order). Generators and judges are both Anthropic models (flagged as a caveat on the card).
- Differs from ours: the README's own numbers show that where a text-only floor is strong, the lens does not beat it (knowledge cutoff tie, hinted cutoff lens below prompt-only, math shortcuts within CI of the floor). That is the same pattern we saw.
- Flag: per-family lens scores are not in the README; only floors are.

### 1.3 camilablank/workspace-lenses (HF model repo)
- URL: https://huggingface.co/camilablank/workspace-lenses (MIT)
- Contents: matched J-lens (`<model>/j-lens/lens.pt`) and R-lens (`<model>/r-lens/lens.pt`) pairs for 8 models: DeepSeek-V4-Flash, Qwen3.5-4B, Qwen3.5-9B, Qwen3.5-27B, Qwen3.6-27B, Gemma-3-27B-it, Qwen3.6-35B-A3B, Qwen3.5-122B-A10B; plus a Template lens for Qwen3.6-27B in two sizes (13,174 rows; 13,731 rows with the "v3 phrase registry"), each with a row-to-word/phrase text file.
- Definitions on the card: J-lens = standard averaged first-order map from layer l to target layer n_layers-2, fitted with the official `jlens.fit`, `skip_first = 4`, on 25 prompts from NeelNanda/pile-10k. R-lens = same estimator but the Jacobian is computed through an LRP-modified backward graph (forward identical, so pairs are matched); author reports "cleaner early-layer readouts". Template lens = cosine of residual activation against whitened template directions for words/phrases, able to name multi-token concepts. J++ is NOT defined on this card (it lives at neuronpedia/jacobian-lens and koayon/jpp-lenses). MoE R-lens rule configs were chosen by sweeps for "best-reading" performance. No evaluation numbers.
- Differs from ours: these are the exact artifacts we used; note the J-lens here was fit on only 25 prompts (the paper's default is 1,000, and the paper says quality saturates quickly, beating baselines at 10 prompts).

### 1.4 Third-party WorkspaceBench numbers (Oracle-lens model cards)
- ceselder/olens-qwen3.6-27b-l42: https://huggingface.co/ceselder/olens-qwen3.6-27b-l42 . 25-family mean (Sonnet-5 judge; 12 workspace-only families): Oracle lens RL 0.405 (workspace-only 0.289, hallucination rate 0.49); SFT-only 0.214; "4 sampled model continuations as bullets" (the SFT target, i.e. just the model's own next text) 0.348; NLA RL (ceselder/qwen3.6-27b-nla-rl) 0.403; J-lens top-10 tokens 0.162 (24 families). Lenses that also read the preceding context reach 0.54-0.56. No prompt-only or logit-lens baseline reported. Card notes the lens was trained on high-entropy pretraining positions and "is likely weaker ... on long chat transcripts".
- camila-blank/qwen3.6-27b-olens-affwhitened-rl600: https://huggingface.co/camila-blank/qwen3.6-27b-olens-affwhitened-rl600 . Opus 5.5 judge (explicitly "not official WorkspaceBench numbers"): default O-lens macro 0.744 / hallucinated share 8.5%; this variant 0.722 / 6.6%; J-lens concept precision/recall@10 0.275/0.502 vs 0.416/0.587. No baselines.
- Takeaway: sampling the model's own continuations (0.348) gets most of the way to the trained verbalizers (0.40), which says much of the WorkspaceBench signal is next-text prediction. J-lens top-10 at 0.162 is the weakest reader on the full benchmark.

### 1.5 MATS follow-up: "Do NLAs read what the model can't say?" (Jarus77/mats-nla-workspace)
- URL: https://github.com/Jarus77/mats-nla-workspace (MATS 12.0, Oct 2026, pre-registered confirmatory run Oct 19-Nov 1 2026; pilot numbers only)
- Summary. Replicates 4 regex WorkspaceBench families at layer 42, n=400, Qwen3.6-27B, and adds the control WorkspaceBench lacks: a text-only model given the prompt scores 0.89; given ONLY the NLA's output 0.60; only the Oracle lens's output 0.56; prompt PLUS reader outputs 0.88 (no gain). Their conclusion: WorkspaceBench "can't separate reading the activation from re-solving the prompt." Also: the Oracle lens's published lead comes from per-item any-layer selection (+0.08-0.22); at a single layer the NLA ties or beats it. Probe-survives-J-removal cannot separate features (every feature keeps >=98% probe accuracy, same as removing a random subspace of equal rank). With a planted bridge entity the NLA "rewrites the prompt's clue to fit the activation" in 12/12 pilot cases. Judge: Gemini 3.8 Flash.
- Differs from ours: this is the closest analogue to our design (same model, same bench, reader output vs text) and reaches the same conclusion: zero uplift from the reader over the text.
- Flag: pilot numbers, not yet confirmed; four families only.

### 1.6 Pilot: nla-vs-lenses (LittleMeHere)
- URL: https://github.com/LittleMeHere/nla-vs-lenses (MATS 12 mini project, Oct 2026)
- Summary. Splits layer-42 activations of Qwen3.6-27B into the projection onto the top 1,024 J-lens directions (16% of squared norm) and the remainder, then asks the NLA and Oracle lens to read each part. On multihop prompts both readers name the hidden step from the J part and rarely from the rest (confirmed on 70 new prompts with pre-fixed tests); no clear NLA advantage over the Oracle lens on hidden steps; the NLA's reconstruction depends most on its restatement of the prompt, and "wrong claims about the topic matter no more than an average piece of text." Numbers beyond n (30, 70) are in a STATUS.md not shown on the landing page.
- Differs from ours: again a multihop-with-hidden-step setting; the finding that the NLA's content is dominated by prompt restatement supports our null.

### 1.7 Fork with causal interventions (BurnyCoder)
- URL: https://github.com/BurnyCoder/workspace-bench-with-causal-interventions
- Summary. Fork of camila-blank/workspace-bench; README says `docs/causal.md` checks "by the J-lens paper's ablation and swap tests" that the bridges the J-lens reads are used. No numbers for any lens, no steering results; arms listed as "to be judged". The only figure is the buggy_code silent-lens floor (2.96). Not a usable source for intervention efficacy.

## 2. The Jacobian-lens family

### 2.1 Verbalizable Representations Form a Global Workspace in Language Models (the J-lens paper)
- Authors: Wes Gurnee, Nicholas Sofroniew (core), Adam Pearce, Mateusz Piotrowski, Isaac Kauvar, Runjin Chen, Anna Soligo, Paul Bogdan, Euan Ong, Rowan Wang, T. Ben Thompson, David Abrahams, Subhash Kantamneni, Emmanuel Ameisen, Joshua Batson, Jack Lindsey (Anthropic). Transformer Circuits, 6 Jul 2026; arXiv 2607.15495.
- URLs: https://transformer-circuits.pub/2026/workspace/ ; https://arxiv.org/abs/2607.15495 ; code https://github.com/anthropics/jacobian-lens (Apache-2.0, "reference implementation, not maintained")
- Definition. J_l = E[dh_final / dh_l], the expectation over source positions t, all later target positions t' >= t, and a corpus of 1,000 pretraining-like 128-token sequences (cotangents summed over targets, averaged over sources). Readout lens_l(h) = softmax(W_U norm(J_l h)); rows of W_U J_l are "J-lens vectors", one per vocabulary token. Logit lens is the special case J_l = I. The "J-space" is the sparse (~25-dim) non-negative span of J-lens vectors. The README says quality saturates fast ("about 100 prompts is usable"; A.7: "beats the logit lens and tuned lens baselines with as few as 10 prompts").
- Evaluation vs other lenses (A.6): six constructed prompt sets (multihop 50, multilingual 54, order-of-ops 55, poetry 52, typo 96, association 50), scored pass@k AUC on whether the latent intermediate appears in top-k. Text says J-lens "outperforms the other lenses on every prompt distribution", tuned lens "recovers almost nothing" on association and poetry; numbers only in Fig. 52. Next-token KL: "The tuned lens is, by construction, the best predictor of the model's output at every depth. The J-lens is the worst, with higher KL than even the uncorrected logit lens through most of the network." Cosine: logit vs tuned ~0.9 in layers 0-33; J-lens nearly orthogonal to both pre-workspace, rising to ~0.7 with the logit lens over layers ~38-58. Ablating J-lens directions on multihop gives ~2x the output KL of logit/tuned directions. There is NO text-only or prompt-only baseline for the lens evals.
- Causal results. Two-hop coordinate swaps succeed 54% (Haiku 4.5), 70% (Sonnet 4.5), 70% (Opus 4.5) over 50 prompts. Category-swap drives target into top-5 on 88% of trials with pure J-lens vectors; the J-space component of a generic concept vector carries a median 6-7% of its variance yet accounts for 59% of swap successes vs 5% for the remainder; in a probe study (n=90) the J component flips 61% vs 28% remainder vs 6% with J-coordinates clamped. Flexible generalization: 76/192 swaps succeed at top-1 (101 at alpha=2); number words worst. Ablation of k=10 directions: heavy ablation drives multi-hop accuracy near zero; classification/extraction/MMLU preserved. Eval-awareness ablation on the blackmail scenario: eval-awareness 71% -> 3%, blackmail 0/180 -> 13/180. Broadcast-head ablation: recall@25 0.86 -> 0.67, top-1 next-token changes at 5% of positions vs 2% control. Feature steering: suppressing a fake/fraud feature reduced verbalized test recognition 28/50 -> 10/50. J-space explains at most ~10% of activation variance. The workspace band is ~layers 38-92 of Sonnet 4.5; "the first third" is noisy and the authors concede the onset "could partly reflect lens artifacts".
- Case studies: planned rhymes, arithmetic intermediates (21, 42, 49), "halfway/done" progress, leverage/manipulation/panic signals, eval-context recognition (fake, fictional), prompt-injection flagging, and in two model organisms "reward"/"bias" and "secretly"/"trick" where "the logit lens surfaces neither". The Opus 4.6 examples are "drawn from a pre-release audit"; no selection procedure is stated. The eval-awareness quantification uses NLA flags as ground truth (J-lens score separates NLA-flagged from unflagged positions at AUC 0.853; 198 of ~94,000 positions flagged) and the paper itself notes this "defines ground-truth based on a potentially unreliable interpretability tool." Auditing benchmark (A.22): 6 transcripts, 18 claims, 0-10 judge; J-lens auditor comparable to NLA on four cases, fails on reward hacking (4.5 vs 10.0) and language switching (6.0 vs 9.9); SAE numbers not in text; no black-box number in text.
- Limitations stated: single-token vocabulary only ("the set of concepts the lens can name is exactly the set of concepts that have a single-token name"); flat bag, no binding; some positions yield tokens the authors "cannot make sense of"; late boundary "somewhat post-hoc"; first-order linear approximation averaged over contexts reflects "general disposition rather than context-specific use".
- Differs from ours: every quantitative eval is lens-vs-lens on items built to hold an unspoken intermediate, scored by whether the intermediate appears at any layer; no text-judge comparison; case studies are audit anecdotes without a selection procedure or a random-position control. For steering, the paper's own numbers say a single J-lens direction is a small (6-10% variance) but causally over-weighted component; full effects need k=10 ablations or coordinate swaps rather than one keyword direction, and even swaps fail 30-46% of the time, which makes a 33% removal from one keyword direction unsurprising.
- Flag: hand-selected case studies; eval-awareness ground truth from another tool; no prompt-only baseline.

### 2.2 Neuronpedia Jacobian-lens docs and neuronpedia/jacobian-lens HF repo
- URLs: https://docs.neuronpedia.org/jacobian-lens ; https://neuronpedia.org/jlens ; https://huggingface.co/neuronpedia/jacobian-lens
- Summary. Interactive demo (Qwen 3.6 27B, Gemma 3 12B, DeepSeek V4 Flash as main tabs; >36 pre-fitted lenses). Demos: Verbal Report (tennis->rugby swap), Directed Modulation (fish/coral/whale while writing about a drawer), Multi-hop (spiders->ants flips eight->six legs), General Broadcast (France->China changes capital/language/continent/currency), Selective Mediation (French->Spanish swap has no effect on anomaly detection), Versus Logit-Lens (J-lens finds toxic/poison the logit lens misses). Stated limitations: "not reliable on the first ~1/3 of layers" (skipped by default), "sometimes misses concepts", small models "oversteer". The HF card lists J++ lenses fitted on WikiText-103 with recall@10: Qwen3.6-27B 55.2%, Qwen3.5-9B 55.0%, Gemma-4-31B 58% (poetry dropped: 1/98 items pass the correctness filter), Olmo-3-32B 50.0%, Qwen3.5-122B-A10B 48.4%, DeepSeek-V4-Flash 61.4%, Qwen3.5-0.8B 44.9%, Qwen3.5-2B 51.5%, Qwen3-4B 53.8%. File format: `logits = unembed(h @ J[l].T)`; source_layers = every block except the final one.
- Differs from ours: all demos are curated swap examples on short factual prompts; no baseline of any kind.

### 2.3 R-lens: making J-lens more faithful on early layers
- Authors: Camila Blank, Agam Bhatia (MATS). LessWrong, 2026. URL: https://www.lesswrong.com/posts/nv8oedrnLXKRzNEL9/r-lens-making-j-lens-more-faithful-on-early-layers ; RelP paper arXiv 2508.21258.
- Summary. "Identical to J-Lens, except that we make minor and low-overhead changes to the backwards pass" using LRP rules (LN-rule on RMSNorm, identity+half rules on gated MLP; MoE: all routed experts, frozen routing, swept shared-expert scale). Evaluated on five categories (multihop, multilingual, association, typo, poetry) with pass@10 at the bolded token across layers; multihop/multilingual filtered to model-correct items. R-lens beats J-lens on pass@10 averaged over the first half of layers for all but the smallest dense and MoE models, with the gap growing with size (largest on DeepSeek-V4-Flash); numbers are in figures. Case studies ("aganst"->"against" at layer 4 vs never for J-lens; sushi->Japan at layer 2 vs 14; Jordan->basketball at 4 vs 20; Verona->Italy rank 1 vs >1000) are illustrative with no stated selection procedure. Ablation: 30 multihop questions, ablate the intermediate's direction at the penultimate position, 8 samples each, GPT-5.4-nano judge: ablating R-lens directions hurts accuracy "much more" than J-lens or logit-lens directions (numbers in figures). Linear-probe upper bound reaches 0.99-1.00 earlier than any lens. The authors say R-lens is "primarily a tool for more faithfully tracking computation over layers, since concepts usually also appear in later layers."
- Comment by StellaAthena: layer-based metrics can be gamed by reporting a later layer; the J-lens paper's metrics "often have this problem"; not answered in the post.
- Differs from ours: the gain is defined as the SAME concept appearing EARLIER; at the late read position we used, the authors expect J- and R-lens to agree, so R-lens cannot add information in our design.
- Flag: hand-picked examples; metrics only in figures.

### 2.4 J++ Lens: Jacobian Filtering Enables More Faithful Workspace Lenses
- Authors: Kola Ayonrinde, Jack Lindsey (Anthropic). LessWrong 8 Oct 2026. URL: https://www.lesswrong.com/posts/nc9dHfcB22JdMzGbr (mirror https://www.greaterwrong.com/posts/nc9dHfcB22JdMzGbr) ; lenses https://huggingface.co/koayon/jpp-lenses
- Summary. Three changes: (1) Jacobian filtering: k-means the activations, fit one "Expert Jacobian" per cluster (8 per layer), combine with learned weights so bad experts get zero/negative weight (removing this costs 11.7 pp of recall@10, ~60% of the gain); (2) LRP backward pass as in R-lens; (3) drop punctuation/whitespace from the readout vocab; also skip the first 16 positions (attention sinks). Fit on 64 WikiText-103 128-token sequences. Metric: recall@10 macro over the five Gurnee tasks, hit if the target is in the top 10 at any of seven layers. Table 1 recall@10 (J / R / J++): Qwen3.5-9B 34.2/37.5/55.0; Qwen3.6-27B 35.7/37.7/55.2; Gemma-4-31B 34.9/46.4/58.0; Olmo-3-32B 32.6/36.2/50.0; Qwen3.5-122B-A10B 24.4/23.2/48.4; DeepSeek-V4-Flash 30.5/47.4/61.4; medians 33.4/37.6/55.1; logit-lens median 31.2. Largest gains in the first quarter of layers. Causal swap eval (Qwen3.6-27B, 67 trials): J++ 59.7%, R 50.7%, J 49.3%. Recall@1 on Qwen3.6-27B: J++ 32.4%. Poetry stays <=5% for every lens. Main case study "retrieve-then-suppress" on directed modulation (440 items; Fig. 8); Appendix A: ablating early-layer concept vectors raises the avoided concept's probability by 2.8 pp (J++) vs 0.36 pp n.s. (J-lens). Authors explicitly "do not claim the lens is yet practically useful for monitoring" and note "the evaluation ceiling is unclear, since models may shortcut without representing the intermediate variable."
- Differs from ours: again the uplift is earlier-layer readout on constructed intermediates; at single late layers the three lenses swap-succeed within 10 pp of each other, and the causal success rate (~50-60%) is the ceiling one should expect from a single lens direction.
- Flag: the "better" lens still reaches only 55% recall@10 at ANY of seven layers on tasks designed for it.

### 2.5 Follow-ups on J-lens interventions (lightly checked)
- "Looped Transformers under the Jacobian Lens" (arXiv 2609.01924): single-direction ablation understates what a band carries; subspace ablation gave 0% / 14% / 88% kept (all / loop-2 / control). "Feature Superposition in Neural Networks" (arXiv 2609.06862) repeats the 6-7% variance vs 88%/5% swap numbers and warns they "limit generalization". Neither was read in full; cited only for the point that one J-lens direction is a narrow slice.

## 3. Other readout methods WorkspaceBench references

### 3.1 Natural Language Autoencoders Produce Unsupervised Explanations of LLM Activations (NLA)
- Authors: Kit Fraser-Taliente, Subhash Kantamneni, Euan Ong, et al. (Anthropic). Transformer Circuits, 7 May 2026. URLs: https://transformer-circuits.pub/2026/nla/ ; https://www.anthropic.com/research/natural-language-autoencoders
- Summary. Activation verbalizer (AV) and activation reconstructor (AR), both copies of the target, trained with GRPO to minimize reconstruction error through a text bottleneck (reward ~ -log squared error, KL penalty for fluency). Warm start reaches FVE 0.3-0.4; training 0.6-0.8, growing ~linearly in log steps. Five prediction tasks improve with training (numbers not in the page text). Case studies: poetry planning ("rabbit" at the newline; editing the explanation and steering with the resulting direction shifts completions to "mouse", but "only about half of steering attempts succeed"); language switching traced to malformed training data; evaluation awareness surfaced on eval transcripts more than deployment traffic, reduced by realism edits; misreported tool calls and reward reasoning ("can hallucinate specifics"). Auditing: agents with NLA access found the root cause of a planted misalignment better than SAE and black-box baselines (rates not in text). Limitations: confabulation "sometimes with contradictory or verifiably false claims"; claims that recur across adjacent tokens are more trustworthy; the AV "can add inferences beyond what the activation contains"; several hundred tokens per activation.
- Differs from ours: headline cases are hidden-information cases (unverbalized eval awareness, a planned rhyme, a planted misalignment) and are selected anecdotes; the one steering result from an edited explanation succeeds ~50%. No transcript-only judge baseline is reported for the eval-awareness claim.
- Flag: hand-selected; auditing numbers not given in text.

### 3.2 Eliciting Latent Predictions from Transformers with the Tuned Lens
- Belrose, Ostrovsky, McKinney, Furman, Smith, Halawi, Biderman, Steinhardt. arXiv 2303.08112 (v1 Mar 2023, v6 Nov 2025). URL: https://arxiv.org/abs/2303.08112
- Summary. Per-layer affine translator trained by KL distillation to match the FINAL-layer next-token distribution. Critique of the logit lens: for BLOOM and OPT-125M the top-1 logit-lens prediction is the input token in more than half the layers; GPT-Neo-2.7B KL from final ~4-5 bits for most layers; bias toward certain vocabulary "until the very end"; trajectories cannot be read as evidence-driven belief updating because the bias is exploitable. Tuned lens: lower perplexity, bias and variance across seeds (figures only); transfer across fine-tunes within 0.3 bits/byte. Causal basis extraction: Spearman 0.89 between a direction's influence on the lens and on the model (Pythia-410M, layer 18). Case study: prompt-injection detection by anomaly detection (isolation forest / LOF) on tuned-lens trajectories, Pythia-12B, nine tasks; near-perfect AUROC on five; a simple baseline is "consistently strong" and beats it on two. The injected text is appended to the prompt and is fully visible.
- Differs from ours: the tuned lens is by construction a next-token predictor (the J-lens paper: it "skips ahead to the output"); its only applied case study detects visible text.

### 3.3 Interpreting GPT: the logit lens (origin)
- nostalgebraist, LessWrong, 31 Aug 2020. URL: https://www.lesswrong.com/posts/AcKRB8wDpdaN6v6ru/interpreting-gpt-the-logit-lens
- Summary. Project intermediate residuals through the unembedding. Observations: early layers uninformative, middle layers already rank the final answer low, input tokens not recoverable after layer 1 (KL jump), copying ("plasma") only becomes visible late. Author's caveat: "a lens" shows "some of what is going on, not all of it"; commenters (evhub et al.) note that activations may hold information logits cannot reveal. Setting: ordinary GPT-2 text with no hidden info; purely qualitative.

### 3.4 Patchscopes
- Ghandeharioun, Caciularu, Pearce, Dixon, Geva. ICML 2024; arXiv 2401.06102. URL: https://arxiv.org/abs/2401.06102
- Summary. Patch a hidden state into a target prompt and let the model verbalize it. Next-token prediction (Pile, LLaMA2-13B/Vicuna-13B/GPT-J/Pythia-12B): token-identity patchscope beats logit and tuned lens from layer ~10 up, gains "up to 98%" in layers 18-22; below layer 10 all methods poor (numbers in Fig. 2). Attribute extraction (GPT-J, 12 relations, 1,453 items): beats a logistic probe on 6/12 (e.g., Country currency 17.7 -> 51.0, Food from country 5.1 -> 63.8), loses on 1. Entity description from early layers: RougeL vs Wikipedia, NO comparison method. Multi-hop correction (Vicuna-13B): 50% vs CoT 35.71% vs vanilla 19.57% on 46 of 1,104 generated samples that met criteria. Limitations: autoregressive LMs only, placeholder contamination.
- Differs from ours: all target information is in the input (subject tokens, attributes known to the model); no hidden state beyond the model's own knowledge; entity-description eval has no baseline; multi-hop eval keeps 46/1,104 items.
- Flag: heavy filtering in the multi-hop study; no text-only baseline.

### 3.5 SelfIE: Self-Interpretation of Large Language Model Embeddings
- Chen, Vondrick, Mao. arXiv 2403.10949, Mar 2024. URL: https://arxiv.org/abs/2403.10949
- Summary. Insert an embedding at layer 3 of a "Sure, I'll summarize your message:" prompt on LLaMA-2-70B-Chat; relevancy score = probability delta with vs without the embedding. Case studies (harmful knowledge recall, prompt injection read as urgency, trolley "conformity", syrup viscosity, social reasoning, "McQueen" hallucination path, 100 deception scenarios heatmap) are qualitative with no stated selection and no baseline. Quantitative: TextWorld entity-state, 3,400 eval samples: zero-shot SelfIE recovers ~60-80%, similar to a linear probe trained on 100 samples. Supervised control on Counterfact (844): harmonic mean 59.77% vs ROME 56.92%; ethical-preference edit flips human-first 100% -> 2% (random control 95%); reinforcement control: harmful responses under injection 89.06% -> 4.4%, Counterfact accuracy 100 -> 95.85%.
- Differs from ours: case studies hand-picked; the only quantified reading task is on information present in the input text; editing results show that editing by the lens's description works at the parameter level, not that a single lens direction removes a behavior.
- Flag: no selection procedure for examples; no text baseline.

### 3.6 LatentQA: Teaching LLMs to Decode Activations Into Natural Language (LIT)
- Pan, Chen, Steinhardt. ICLR 2026; arXiv 2412.08686 (v2 Mar 2026). URL: https://arxiv.org/abs/2412.08686
- Summary. Decoder copy of the target fine-tuned on ~16.7k (activation, QA) pairs generated with o1-preview (controls: extractive QA, goals, personas); reads layer 15, writes to layer 0. Reading: hidden system prompt recovery, LIT beats GPT-4 by 18.7% (hard) / 2.7% (easy) and SelfIE by ~77%; relation extraction on Llama-3-8B-Instruct +32.2 points over linear probes, +38.2 over Patchscope (loses on 1/6). The decoder sees only user-portion activations, GPT-4 sees the full dialog. Control: CrowS-Pairs bias 4.05 -> 3.70, stereotype 64.3% -> 60.9% (RepE made it worse, 4.38); harmful-knowledge steering 100% harmful on harmful prompts but 87% on benign ones. Scaling 1B/3B/8B: 30/96/100 easy, 12/88/92 hard. Limitations: three control types; "without ground-truth latents, the decoder may hallucinate".
- Differs from ours: the hidden-system-prompt task is a hidden-information task by design (the prompt is hidden from the decoder but a text baseline that sees it exists); Li et al. (3.8) later show the relation-extraction gains vanish against a zero-shot text baseline.

### 3.7 Activation Oracles: Training and Evaluating LLMs as General-Purpose Activation Explainers
- Karvonen, Chua, Dumas, Minder, et al. ICML 2026 oral; arXiv 2512.15674 (v1 Dec 2025). URL: https://arxiv.org/abs/2512.15674 ; code https://github.com/adamkarvonen/activation_oracles
- Summary. LoRA-tuned LLMs that take activations (norm-matched, added at layer 1) plus a question; trained on ~1M examples (SPQA + 7 yes/no classification tasks + self-supervised context prediction) from 25/50/75% depth. Secret-keeping evals: Taboo 21% vs 4% best prior white-box; SSC 59% vs 52%; User Gender 91% (SPQA-only best); beats the best black-box ("The secret is..." prefill) on 2/3. Emergent-misalignment diffing: AO and ADL both 2/5 on the rubric, slightly above black-box. PersonaQA (facts fine-tuned into the model): 5% -> 14% open-source, Haiku 3.5 35%, "configurations within error". Limitations: "The model frequently makes incorrect guesses", not trained for uncertainty; on hallucination detection "simple prompting baselines performed strongly"; evals are "narrow, controlled fine-tunes and auditing games". Follow-up "Building Better Activation Oracles" (May 2026, not read) reports hallucination and vagueness problems.
- Differs from ours: every headline task is a secret the model is trained to withhold from the text (Taboo, SSC, fine-tuned facts), i.e., the only regime where an activation reader can in principle beat a text reader; even there margins are 7-17 points and on diffing the AO ties a non-verbal baseline.

### 3.8 Do Activation Verbalization Methods Convey Privileged Information? (critique)
- Millicent Li, Alberto Mario Ceballos Arroyo, Giordano Rogers, Naomi Saphra, Byron C. Wallace. ICML 2026; arXiv 2509.13316 (v1 Sep 2025, v4 May 2026). URL: https://arxiv.org/abs/2509.13316
- Summary. Tests Patchscopes and LIT (LatentQA) on the Hernandez relation-extraction benchmark and on PersonaQA variants. Feature extraction average accuracy: Llama-3 LIT 0.64, Patchscopes 0.38, ZERO-SHOT TEXT 0.64; Ministral LIT 0.61, Patchscopes 0.27, zero-shot 0.68: "Neither verbalization method outperforms a zero-shot baseline without access to the target model state." Reconstructed inputs fed to the verbalizer match LIT on most tasks. PersonaQA-Shuffled: the verbalizer answers from its own knowledge better than from the target's; PersonaQA-Fantasy (facts the base model cannot know, fine-tuned into the target): neither method exceeds zero on any attribute. Verbalizer-knows-more condition: Patchscopes/LIT score above zero on attributes the target LACKS (LIT favorite food 0.45), where faithful decoding would give zero. Conclusions: "A naive application of verbalization approaches may lead to an illusion of interpretability"; "we need controlled evaluations for measuring verbalization ability"; feature-extraction benchmarks "may therefore only be useful as a diagnostic."
- Differs from ours: this is our design applied to the 2024-25 verbalizers, and it reaches our conclusion: with a matched text baseline the uplift disappears.

### 3.9 Natural Language Autoencoders Identify Without Explaining (critique)
- Kristina Sekrst, Barbara Geld. ISPSM 2026; arXiv 2610.32691, 23 Oct 2026. URL: https://arxiv.org/abs/2610.32691
- Summary (abstract only; no experiments). Round-trip reconstruction tests whether the text carries enough information to IDENTIFY the activation, "not descriptive faithfulness"; a text can pick out an activation while misdescribing what it does; NLAs thereby reintroduce the unverified-introspection problem they were meant to solve. Conceptual, no numbers.

### 3.10 Train the Model, Not the Reader: Decodability Supervision for Verifiable Activation Explanations (critique)
- Hiskias Dingeto. arXiv 2607.20379 (v1 Jul 2026, v2 Aug 2026). URL: https://arxiv.org/abs/2607.20379
- Summary. Reconstruction scoring "is structurally insensitive to individual claims": flipping a claim that does not change the reconstruction is never penalized; verbalizers pass by conveying gist or by "co-adapted private codes". On a released Qwen-2.5-7B verbalizer only ~2% of specific claims are ones the reconstruction depends on. Proposes RECAP (co-trained probe heads) at +0.001 nats reconstruction cost; independent probe ranks true above false claims at AUC 0.96 vs 0.82 without; against an adversarial editor the RECAP probe stays at 0.95 while the control falls to 0.51. Mostly sandbox models plus Pythia-160M.
- Differs from ours: methodological; supports scoring individual descriptive claims with a blind judge rather than trusting reconstruction, which is what we did.

### 3.11 Future Lens: Anticipating Subsequent Tokens from a Single Hidden State
- Pal, Sun, Yuan, Wallace, Bau. CoNLL 2023; arXiv 2311.04897. URL: https://arxiv.org/abs/2311.04897
- Summary. On GPT-J-6B, a single hidden state predicts tokens 2+ positions ahead with "more than 48% accuracy" at some layers (linear approximation and causal patching; per-offset numbers in the paper body, not read). Relevant because it establishes that mid-layer residuals already carry the upcoming text, so a lens reading them will, in ordinary chat, mostly recover what the transcript is about to show.

### 3.12 Interpreting Language Model Hidden States at Scale (OmniLens)
- Pettyjohn, Sakarvadia, Hudson, McKenzie, Chard, Foster. arXiv 2608.10260, 10 Aug 2026. URL: https://arxiv.org/abs/2608.10260
- Summary. Low-rank trained lenses for every component (482 lenses on LLaMA-3.3-70B; 98.4% fewer parameters; Subset-KL training). Reproduces prompt-injection detection, multi-hop memory injection and toxicity localization. Key sentence: "the components where a behavior is most visible need not be those where intervention is most effective." No text-only baseline, no verbalizer comparison.
- Differs from ours: engineering paper; the quoted line is the one relevant point for our 33% steering result.

## 4. Critiques of lens methods, consolidated
1. Lenses read the next-token distribution. The tuned lens is trained to match the output (Belrose et al.; J-lens paper: it "skips ahead to the output"). The logit lens agrees with the tuned lens at cosine ~0.9 through the first third of depth and with the J-lens at ~0.7 in the workspace band (J-lens A.6). The J-lens is deliberately the WORST next-token predictor, but its own authors measure its content only as "does the intermediate appear in top-k at any layer", never as "does it tell a reader something the text does not".
2. Early layers are unreliable for all of them: J-lens "not reliable on the first ~1/3 of layers" (Neuronpedia), R-lens/J++ exist to fix this, and the J-lens paper concedes the workspace onset "could partly reflect lens artifacts." StellaAthena's comment on the R-lens post: layer-choice metrics can be gamed.
3. "Lens says X" correlates with what the model is about to say. The Oracle-lens SFT target (the model's own sampled continuations) scores 0.348 on WorkspaceBench vs 0.405 for the trained lens; Future Lens shows >48% future-token recoverability; the MATS control finds prompt-only 0.89 vs prompt+reader 0.88.
4. Verbalizers import the reader's knowledge: Li et al. (zero-shot ties LIT; verbalizers answer above zero for facts the target lacks); WorkspaceBench README (knowledge-cutoff family: text-only Qwen 0.486 ties the lens); the MATS pilot (NLA rewrites the prompt's clue to fit the activation 12/12).
5. Reconstruction does not certify claims: Dingeto (2% of claims load-bearing), Sekrst & Geld, WorkspaceBench ("nearly every NLA readout contains some type of claim" contradicted by the context; hallucination rate 0.39-0.49 on the ceselder card).
6. Steering with lens-derived directions is partial: J-lens paper coordinate swaps succeed 54-70% (two-hop) and 76/192 (generalization); a single J-lens direction holds 6-7% of a concept vector's variance; k=10 ablations are needed for behavioral effects and still leave classification intact; NLA-edit steering succeeds "about half" the time; OmniLens: where a behavior is most visible is not where intervention is most effective; the looped-transformer follow-up says single-direction ablation understates what a band carries. A 33% reduction from one keyword direction sits inside this range.

## 5. Why their settings differ from ours (one paragraph)
WorkspaceBench, the J-lens/R-lens/J++ evals and the verbalizer papers all score a reader on whether it names a target that was engineered to be absent from the text (an unspoken intermediate, a planned rhyme, a withheld secret, a fine-tuned fact), with the pass rule "any layer, any position", lens-vs-lens comparisons, and a prompt-only floor that is reported but not subtracted. Our design removes every one of those advantages: there is no hidden target, the behavior is visible in the transcript once it happens, all methods read the one position the text judge reads, and the score is a blind judge's AUROC against the text judge. The three sources that come closest to our design (Li et al. ICML 2026; the WorkspaceBench README's knowledge-cutoff / hinted-cutoff / math-shortcut floors; the Jarus77 MATS control) all find zero uplift of the reader over the text, so our .51-.54 vs .56 is the expected result rather than a failure of our pipeline. The intervention literature likewise predicts a partial effect from a single lens direction (50-70% swap success, k=10 ablations, half of NLA-edit steerings succeeding), so 33% is within prior art, not below it.
